# GigaByte's template class

`oup-contemporary.cls`, `vancouver-authoryear.bst` and `gigabyte.png` are the files of GigaByte's
Overleaf template, "Template for GigaByte Journal Technical Report Submissions" (River Valley
Technologies Ltd and GigaScience, CC BY 4.0;
https://www.overleaf.com/latex/templates/template-for-gigabyte-journal-technical-report-submissions/yjnmwdcjsmrc),
unchanged. `make gigabyte` in `manuscript/` compiles `gigabyte.tex` with them.
